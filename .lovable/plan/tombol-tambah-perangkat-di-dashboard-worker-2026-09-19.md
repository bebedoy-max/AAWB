# Tombol Tambah Perangkat di Dashboard Worker

## Perubahan
- Tambahkan tombol **Tambah Perangkat** di pojok kanan bawah kartu **Perangkat Terhubung** tanpa mengubah tinggi kartu.
- Saat tombol ditekan, tampilkan formulir nama perangkat yang sama seperti pada menu WhatsApp.
- Setelah nama dikonfirmasi, buat perangkat lalu arahkan pengguna ke halaman WhatsApp agar proses pemasangan dapat dilanjutkan.
- Terapkan batas maksimal empat perangkat dan tampilkan pesan jika pembuatan gagal.

## Verifikasi
- Pastikan posisi tombol tidak memperbesar atau menggeser kartu statistik.
- Uji formulir, pembuatan perangkat, dan perpindahan ke halaman WhatsApp.
