# Pairing Perangkat dari Dashboard Worker

## Perubahan
- Setelah nama perangkat dikonfirmasi, tetap berada di dashboard dan tampilkan QR pemasangan.
- Tambahkan pilihan pemasangan melalui kode di bawah QR, termasuk input nomor WhatsApp dan kode yang dapat disalin.
- Pantau status perangkat secara otomatis selama pop-up terbuka.
- Setelah perangkat benar-benar terhubung, tutup pop-up dan arahkan ke menu WhatsApp.
- Pertahankan batas maksimal empat perangkat dan penanganan error yang sudah ada.

## Verifikasi
- Uji alur nama perangkat → QR/kode → status terhubung → menu WhatsApp.
- Pastikan perangkat yang belum terhubung tidak langsung memindahkan pengguna.
